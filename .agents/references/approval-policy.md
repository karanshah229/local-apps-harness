# Approval policy

Proceed automatically with inspection, implementation, local previews, tests, screenshots, health checks, reversible configuration, local builds, and Git checkpoints.

Ask one plain-English consequence question immediately before live deploy/restart, destructive or meaning-changing migration, restore overwrite, deletion, public exposure, paid resources, access-policy changes, TestFlight upload, or host software installation. Approval for one target and action does not authorize a broader target or later action.
