# Test user journeys

1. Read `../../references/verification-contract.md`; derive journeys from confirmed acceptance examples, not from imagined capabilities.
2. Use the real registered route, API, representative data, and affected mobile platforms.
3. Exercise relevant loading, empty, success, validation, failure, retry, responsive, accessibility, and permission states.
4. For visible UI, read `../../references/ui-styling.md` and compare screenshots or recordings with its visual-language contract.
5. Report results in product language and flag visible behavior without a requirement.

Complete when every acceptance example, affected regression, and applicable verification-matrix row has observable evidence.
