# Change an application

1. Require a bounded requirement ledger and connected-change record.
2. Preserve a local Git checkpoint.
3. Implement only confirmed visible behavior through the affected frontend, desktop, backend, data, or mobile build skills while completing every technical surface.
4. Couple database, route, environment, container, desktop, or mobile identity changes to their specialist skills.
5. Run affected tests and `verify-connected-change`.

Complete when acceptance examples pass, affected regressions pass, the registry matches reality, and no new visible behavior lacks a requirement.
